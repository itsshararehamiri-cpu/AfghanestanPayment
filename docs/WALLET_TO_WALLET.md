# Wallet-to-Wallet (W2W) — همراه‌پی

این سند مشخصات تراکنش **کیف به کیف (Wallet-to-Wallet)** را برای اپلیکیشن **همراه‌پی** شرح می‌دهد. منبع الزامات: سند APS (Afghanistan Payments System).

---

## ۱. تعریف

تراکنش W2W انتقال وجه بین دو کیف پول EMI است، بدون دخالت صادرکننده کارت. APS درخواست را اعتبارسنجی می‌کند، کارمزد را اعمال می‌کند و کیف پول مقصد را به‌صورت بلادرنگ شارژ می‌نماید.

---

## ۲. جریان تراکنش (APS)

1. مالک کیف پول مبدأ درخواست W2W را از اپ یا کانال EMI آغاز می‌کند.
2. EMI فرستنده مالک را احراز هویت و جزئیات (وضعیت کیف، موجودی، سقف) را بررسی می‌کند.
3. EMI فرستنده حساب مبدأ را بدهکار می‌کند.
4. EMI فرستنده درخواست W2W را به APS ارسال می‌کند.
5. APS اعتبارسنجی، کنترل تکراری، کارمزد و تشخیص EMI گیرنده از BIN مقصد را انجام می‌دهد.
6. در صورت موفقیت، APS درخواست را به EMI گیرنده می‌فرستد.
7. EMI گیرنده کیف مقصد را اعتبارسنجی و شارژ می‌کند.
8. EMI گیرنده نتیجه را به APS برمی‌گرداند.
9. APS پاسخ نهایی (تأیید/رد) را به EMI فرستنده می‌دهد.
10. پردازش End-of-Day (EOD).
11. فایل‌های تطبیق به EMI فرستنده و گیرنده.
12. فایل‌های تسویه به بانک مرکزی (DAB).

---

## ۳. فرمت شماره کیف پول

```
WalletNumber = BIN (۶ رقم) + ActualWalletNumber (۱۰ رقم)
```

| قانون | شرح |
|--------|-----|
| طول کل | ۱۶ رقم |
| کاراکتر | فقط عدد |
| BIN | ۶ رقم اول؛ باید ثبت و فعال باشد |
| استاندارد | BIN تخصیص‌یافته APS مطابق ISO/IEC 7812 |

## ۴. پیام ISO 8583 (همراه‌پی)

### درخواست مالی (Sender EMI)

| فیلد | مقدار |
|------|--------|
| MTI | `1100` |
| DE3 (Processing Code) | `400000` |
| DE24 (Function Code) | `785` |
| DE2 | شماره کیف پول **مبدأ** (۱۶ رقم) |
| DE4 | مبلغ |
| DE48 تگ 004 | `000` |
| DE48 تگ 012 | `2` |
| DE48 تگ 040 | `1` |
| DE48 تگ 021 | شماره کیف پول **مقصد** (۱۶ رقم) |
| DE48 تگ 049 | نام دارنده مقصد (پس از استعلام نام) |

### پاسخ (MTI 1110)

| فیلد | شرح |
|------|-----|
| DE39 | کد پاسخ (`000` = موفق) |
| DE38 | کد تأیید |
| DE48 تگ 021 | شماره کیف پول |
| DE48 تگ 025 | مرجع تراکنش |
| DE54 | موجودی (در صورت برگشت) |

### استعلام نام (قبل از تراکنش)

| فیلد | مقدار |
|------|--------|
| MTI | `1100` |
| DE3 | `350000` |
| DE24 | `651` |
| DE2 | کیف پول مبدأ |
| DE48 تگ 021 | کیف پول مقصد |

## ۵. جریان UI در اپ همراه‌پی

```
منوی اصلی → «کیف به کیف»
    → ورود کیف مبدأ / مقصد / مبلغ
    → استعلام نام دارنده مقصد
    → صفحه تأیید
    → ورود رمز (PIN)
    → نتیجه موفق / ناموفق + رسید
```

### ماژول‌ها

| لایه | مسیر |
|------|------|
| UI | `feature/wallet_to_wallet/` |
| ISO / Handler | `psp/hp/wallet_to_wallet/` |
| API | `transaction/api/` (`WalletToWalletInput`, `TransactionType.WALLET_TO_WALLET`) |

### محدودیت‌ها

- فقط flavor **HP (همراه‌پی)** — در BP stub برمی‌گردد.
- آیتم منو: `MenuItemType.WALLET_TO_WALLET` در `ENABLED_FEATURES` flavor HP.
- اعتبارسنجی UI: هر دو کیف ۱۶ رقم، مبدأ ≠ مقصد، مبلغ > 0.
